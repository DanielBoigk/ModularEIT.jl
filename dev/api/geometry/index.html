Meshes & Electrodes

ModularEIT.EITMesh — Type
EITMesh{T<:Real}

A two-dimensional triangular mesh of the measurement domain.

Fields

  • nodes::Matrix{T}: 2 × N matrix of node coordinates.
  • elements::Matrix{Int}: 3 × M matrix of node indices, one column per triangle.
  • boundary::Vector{Int}: indices of the nodes on the domain boundary, ordered counter-clockwise.

See also circle_mesh.

source
ModularEIT.circle_mesh — Function
circle_mesh(n::Integer; radius=1.0) -> EITMesh

Create a fan-triangulated disc with n boundary nodes and one centre node.

This is a mock mesh generator; a real implementation would call Gmsh.

Examples

julia> mesh = circle_mesh(16);

julia> nnodes(mesh), nelements(mesh)
(17, 16)

Electrodes

ModularEIT.Electrode — Type
Electrode{T<:Real}

An electrode of the Complete Electrode Model.

Fields

  • nodes::Vector{Int}: boundary nodes covered by the electrode.
  • impedance::T: contact impedance $z_\ell > 0$.
source
ModularEIT.ring_electrodes — Function
ring_electrodes(mesh::EITMesh, L::Integer; impedance=1e-2) -> Vector{Electrode}

Place L equally spaced point electrodes on the boundary of mesh.

Examples

julia> els = ring_electrodes(circle_mesh(32), 8);

julia> length(els)
8
