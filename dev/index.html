ModularEIT

Modular building blocks for Electrical Impedance Tomography (EIT): finite element discretizations, electrode models, forward solvers, adjoint-state and Kohn–Vogelius objectives and projected linear solvers that can be combined freely.

source

Installation

using Pkg
Pkg.add(url="https://github.com/DanielBoigk/ModularEIT.jl")
